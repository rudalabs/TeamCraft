File formats

TeamCraft stores files of any type. It recognises the native formats of these CAD programs and the neutral exchange formats: the file list shows what a file is, the item search filters by CAD program (or finds “SolidWorks”, “NX”, “CATIA product”, …), and every save of a Creo file (bracket.prt.7) becomes a new version of bracket.prt.

Good to know

  • 3D preview in the browser for {% for p in previews %}{{ p }}{% if not loop.last %}, {% endif %}{% endfor %}. Native files (SolidWorks, NX, Creo, CATIA, Inventor, …) need the CAD program’s own kernel – attach a STEP export next to them (e.g. Save as → STEP AP242), then the revision shows it in 3D.
  • Same extension, two programs: .prt is NX or Creo and .asm Creo or Solid Edge – TeamCraft tells them apart by the file content (heuristic: Creo files start with a #UGC: header, Solid Edge files are OLE compound documents).
  • Upper and lower case do not matter (.CATPart, .SLDPRT).
  • Searched inside the file: the names in STEP/IGES files and the text of text based formats (marked below).
  • Siemens Teamcenter is a PLM system, not a CAD program: it manages NX files and uses .jt for lightweight visualisation and PLM XML for structures.
