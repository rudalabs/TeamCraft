AI

Which AI your users work with in TeamCraft: the company AI on the server (Ask TeamCraft) and local agents on their own computers. Both are set in the server configuration and take effect at the next restart. Configuration guide

{% if mode == "company-ai" %}

Company AI only: users ask Ask TeamCraft, which runs on the provider configured below with each user's rights, per-question audit records and the server's limits. Local agents and the MCP endpoint are off; the desktop app's Agent view runs on the company AI, with no local option.

{% elif mode == "no-ai" %}

Local agents are off and no assistant is configured: users have no AI in TeamCraft. Set TEAMCRAFT_ASSISTANT_PROVIDER and its key to offer the company AI.

{% elif mode == "both" %}

Users can ask Ask TeamCraft and may also connect their own local agents with their own AI provider (in the desktop app's Agent view they choose between both). Set TEAMCRAFT_LOCAL_AGENTS=off to keep AI use on the company AI.

{% else %}

No assistant is configured; users may connect their own local agents with their own AI provider.

{% endif %}
