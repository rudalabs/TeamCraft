Result extraction templates

Simulation key numbers are never read out of big result files. A template finds one number in a small text file (solver log, Fluent report or transcript, Nastran .f06, summary .txt/.csv/.html; at most the first 2 MB, and for “use the last” the last 2 MB as well) when it is checked in with a simulation revision of this group; the value is stored with its file and line. A teamcraft-results.json or .csv checked in with the revision does the same without any template.
