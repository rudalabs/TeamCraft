Which files work

  • Autodesk Inventor: BOM editor → Structured (all levels) → Export Bill of Materials as CSV or Excel.
  • SolidWorks: BOM table → Save As Excel or CSV; indented BOMs number their rows 1, 1.1, 1.1.2.
  • Other programs and hand-made lists: a header row with columns such as Part Number / Teilenummer, Name / Benennung, Description, QTY / Menge, Unit / Einheit, Material / Werkstoff, Mass / Masse; the structure comes from a Level / Ebene column (0- or 1-based, also .1, ..2) or from dotted positions.
  • STEP assemblies (AP203, AP214, AP242) of any CAD program: the product structure becomes items and BOM – part number from the product id, name and description from the product, quantity = number of placed occurrences. A new assembly keeps the STEP file, so its 3D preview shows the whole assembly. The geometry of the parts is not split into the items.
  • Rows with the same part number are one item; components marked Reference (Inventor BOM structure) are left out. German number formats (2,5) and units in cells (125 g, 4 Stk) are understood.

The column recognition is a heuristic built from the documented export layouts of these programs; it was not tested with files from every CAD program. If a column is not recognised, rename it in the spreadsheet – the preview shows which columns were used.
