# Code of Conduct

TeamCraft follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. This is a short reference; the full text there is the reference
for interpretation.

## Expected behaviour

- Be respectful and constructive in issues, pull requests, reviews and chats.
- Assume good faith and give clear, specific feedback about the work, not the
  person.
- Keep private information of others, such as personal data or customer data
  from a deployment, out of issues and pull requests.

## Scope

This code applies in all project spaces (the repository, its issues, pull
requests and discussions) and when a person represents the project in public.

Security problems are not Code of Conduct reports; follow
[SECURITY.md](SECURITY.md) for them.
