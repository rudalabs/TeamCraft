# TeamCraft documentation

TeamCraft is an open-source **product lifecycle management (PLM)** system
written in pure Rust: one binary that serves a web interface, a JSON REST API
and a command line, on top of PostgreSQL. It manages the engineering data of
a team – items, revisions, CAD files and their versions, bills of materials,
change orders – with the check-out / check-in discipline of an engineering
vault.

> **Work in progress: there is no official release yet.** TeamCraft is under
> active development (version 0.x). Features, the REST API, the configuration
> and the database schema can still change. You are welcome to try it out
> and test it, and please report what you find on
> [GitHub](https://github.com/rudalabs/TeamCraft/issues). It is provided
> **"as is", without warranty of any kind** (MPL-2.0, sections 6 and 7).
> Don't use it for production data yet, and keep backups.

## The main pieces

| Module                 | Role                                                                                           |
|------------------------|------------------------------------------------------------------------------------------------|
| `domain`               | pure rules: roles, lifecycle states and transitions, revision letters, validation              |
| `services`             | business logic – the only code that writes to the database (permissions, row locks, audit log) |
| `web`                  | server-rendered HTML interface (cookie sessions, CSRF protection, strict CSP)                  |
| `api`                  | JSON REST API under `/api/v1` (bearer tokens)                                                  |
| `vault`                | content-addressed file storage (`objects/ab/cd/<sha256>`)                                      |
| `cadformat`, `cadrefs` | file formats of the CAD programs, references inside CAD files                                  |
| `mesh`, `preview`      | pure-Rust readers for the 3D preview (meshes, point clouds, STEP via the truck kernel)         |

## Platforms

service it needs is PostgreSQL. Step-by-step guides:
