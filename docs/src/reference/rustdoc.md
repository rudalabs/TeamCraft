# Rust API (rustdoc)

The crate documentation of the `teamcraft` library – every module, type and
function with its doc comments – is generated by `rustdoc` and published
next to this book:

**[Open the Rust API documentation](../api/teamcraft/index.html)**

Build it locally:

```sh
cargo doc --no-deps --lib --open
```

Good entry points: `teamcraft::domain` (the rules), `teamcraft::services`
(the business logic), `teamcraft::cadformat` (the format registry) and
`teamcraft::mesh` (the 3D readers).
